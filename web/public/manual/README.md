# マニュアル用スクリーンショット置き場

操作マニュアル（/manual）で表示する画像をこのフォルダに置きます。
ファイル名は下記のとおりにしてください（マニュアル側がこの名前で参照しています）。

- `物件を検索の画面.png` … ATBBで物件条件を検索する画面
- `検索条件の保存とタイトルの入力.png` … 検索条件を保存しタイトルを入力する画面
- `LINEのユーザID確認.png` … LINEユーザー一覧で表示名を検索する画面
- `LINEの表示名の検索結果.png` … 表示名で検索した結果
- `検索条件保存のタイトル入力例.png` … タイトル入力例（{LINEユーザーID}_xxx）

## 注意（公開リポジトリのため必須）

このフォルダの画像は **認証なしで誰でも直接URLで取得できます**
（`/manual` 画面はログイン必須ですが、静的ファイルはガードの対象外です）。

差し替え・追加する際は、以下が写り込んでいないか必ず確認してください。

- 顧客の氏名・LINE表示名・LINEユーザーID
- 管理画面のログインメールアドレス
- ATBBの会社名・元付業者名・電話番号・宅建免許番号・物件所在地
- 「広告転載 不可」表示のある物件情報

写り込む場合は黒塗り、またはダミーデータで撮り直してから配置してください。
