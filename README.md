# 🌕 Lunar Estate Notifier

月面の賃貸物件を24時間監視し、新着のクレーター物件をLINEで通知するシステムです。

地球の不動産市場の高騰を受け、月面移住を検討する層が急増しています。
本システムは月面不動産流通機構（LREINS）の物件データベースを定期巡回し、
お客様の希望条件に合う新着区画を見つけ次第、即座にお知らせします。

## 主な機能

- 🏠 **新着クレーター物件の自動検知** — 静かの海・嵐の大洋・コペルニクス周辺に対応
- 🌗 **重力補正済み家賃表示** — すべての賃料は地球重力換算（1/6補正）で表示
- 🫧 **酸素供給設備フィルタ** — 与圧ドーム付き物件のみに絞り込み可能
- 🚀 **通勤利便性スコア** — 最寄りの質量ドライバー射出場までの徒歩分数を自動計算
- 📡 **LINE通知** — 地球・月間の通信遅延（約1.3秒）を考慮したリトライ設計

## 動作環境

- Node.js 22 以上
- 月面基地からの安定したダウンリンク回線
- レゴリス耐性のあるキーボード（推奨）

## 対応予定

- [ ] 火星物件（ダスト嵐による内見中止の自動振替）
- [ ] ラグランジュ点ステーションの区分所有
- [x] 地球の物件 → 対応予定はありません
